# Weekly Invest Bot - ربات سرمایه‌گذاری هفتگی

ربات کامل تلگرام با قابلیت‌های زیر:

## ویژگی‌ها

- ✅ **کپچا** در شروع (ریاضی ساده با دکمه‌های انتخابی)
- ✅ **چندزبانه** (فارسی + انگلیسی) با دکمه‌های رنگی
- ✅ **سرمایه‌گذاری (Invest)** — درخواست واریز + TXID + تایید توسط ادمین
- ✅ **سود هفتگی ۵٪** روی مبلغ سرمایه‌گذاری‌شده (خودکار هر ۷ روز)
- ✅ **لیدربورد** در ۴ بخش: سرمایه‌گذاری، موجودی، سود، دعوت‌ها
- ✅ **پشتیبانی** — ارسال پیام مستقیم به ادمین
- ✅ **سیستم دعوت (Referral)**
- ✅ **پنل ادمین کامل**:
  - آمار کلی
  - تایید/رد واریزها
  - اعمال دستی سود هفتگی به همه
  - مشاهده پیام‌های پشتیبانی
  - ارسال همگانی (Broadcast)
- ✅ دکمه‌های اینلاین با ایموجی رنگی
- ✅ دیتابیس SQLite سبک و سریع
- ✅ همه دکمه‌ها تست‌شده و کار می‌کنند

## نصب و راه‌اندازی

### ۱. کلون یا دانلود

```bash
git clone https://github.com/rezanb111/weekly-invest-bot.git
cd weekly-invest-bot
```

### ۲. نصب پکیج‌ها

```bash
pip install -r requirements.txt
```

### ۳. تنظیمات

فایل `config.py` را باز کنید:

- `BOT_TOKEN` را از @BotFather بگیرید و جایگزین کنید
- `ADMIN_IDS` را با آیدی عددی تلگرام خودتان پر کنید (از @userinfobot بگیرید)
- `SUPPORT_USERNAME` را تنظیم کنید
- در صورت نیاز `WEEKLY_PROFIT_PERCENT` و `MIN_INVEST_AMOUNT` را تغییر دهید

یا فایل `.env` بسازید:

```
BOT_TOKEN=123456:ABC-DEF...
```

### ۴. اجرا

```bash
python bot.py
```

## ساختار فایل‌ها

```
weekly-invest-bot/
├── bot.py          # فایل اصلی ربات + همه هندلرها
├── config.py       # تنظیمات + متن‌های چندزبانه
├── database.py     # دیتابیس SQLite + توابع سود و لیدربورد
├── keyboards.py    # کیبوردهای اینلاین با دکمه‌های رنگی
├── requirements.txt
└── README.md
```

## نکات مهم

- سود هفتگی به صورت خودکار وقتی کاربر منوی اصلی را باز کند چک و در صورت گذشت ۷ روز اعمال می‌شود.
- ادمین می‌تواند از پنل، سود را به صورت دستی برای همه اعمال کند.
- برای واریز واقعی، کاربر TXID می‌فرستد و ادمین تایید می‌کند.
- دکمه‌های ساپورت و اینوست کاملاً کار می‌کنند و به state مناسب می‌روند.
